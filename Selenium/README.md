# Selenium Project

This is a sample project using Selenium for browser automation.

## Usage
1. Create a virtual environment (recommended):
   ```bash
   python -m venv env
   ```

2. Activate the virtual environment:
   - On Windows (cmd):
     ```cmd
     env\Scripts\activate
     ```
   - On Windows (bash/Git Bash):
     ```bash
     source env/Scripts/activate
     ```
   - On macOS/Linux:
     ```bash
     source env/bin/activate
     ```

3. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the program:
   ```bash
   python main.py
   ```

5. Deactivate the virtual environment when done:
   ```bash
   deactivate
   ```

6. (Optional) Remove the virtual environment folder:
   ```bash
   # Make sure the environment is deactivated first
   rm -rf env  # On macOS/Linux
   # or
   rmdir /s /q env  # On Windows (cmd)
   ```
