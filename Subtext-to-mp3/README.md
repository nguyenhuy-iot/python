# Subtext to MP3

## 📁 Folder Structure

```
subtext-to-mp3/
├─ srt_to_mp3.py
├─ subtitle_vi.srt
└─ voice_vi.mp3   (generated after running)
```

---

## ▶️ Run Command

Inside the `subtext-to-mp3` folder, run:

```bash
python srt_to_mp3.py
```

If successful:

```
DONE: voice_vi.mp3
```

The file `voice_vi.mp3` will be generated in the same folder and can be played together with the video.
